# SOC Agent Roadmap

## 产品定位

SOC Agent 是一个面向 macOS 桌面软件的可观测自动化工具。它优先使用确定性操作完成
任务，并将视觉模型用于截图验证和异常恢复，最终输出可审计的执行报告。

目标场景：

- 没有 API 的桌面软件回归测试
- 企业旧系统的批量录入、查询和导出
- 需要人工确认的跨应用办公流程
- 需要截图、步骤耗时和失败原因的质量检查

非目标：

- 无人监管的支付、退款和审批
- 绕过验证码、风控或权限控制
- 第一阶段同时支持多个操作系统
- 用视觉模型替代全部业务规则

## 下一里程碑

### M1：可靠的单机 QA

- 任务参数化
- 数据驱动测试用例
- 任务重试和失败恢复
- 更完整的视觉断言
- 失败截图和日志归档

### M2：可维护的自动化工作流

- 多应用任务编排
- 条件分支和循环
- 任务前准备与任务后清理
- 批量报告和汇总
- CI 触发真实 macOS Runner

### M3：企业 RPA 基础能力

- 敏感应用和区域遮挡
- 操作审批节点
- 任务队列和调度
- 审计日志与权限隔离
- 多机器执行

## 质量指标

- 单任务成功率不低于 90%
- 失败报告必须包含失败步骤、错误和截图
- 单元测试覆盖所有纯逻辑和策略模块
- 所有高风险动作必须显式确认
- 不允许视觉模型绕过安全策略
